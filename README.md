# GOLDEN SHINE MARBLE

تطبيق Android Native لإدارة عروض الأسعار وعقود المقاولات.

## المنفذ حالياً
- Kotlin + Jetpack Compose، واجهة عربية RTL.
- تخزين محلي باستخدام Room.
- عروض أسعار وعقود ببادئات وترقيم مستقل.
- بند تسعير بالمتر المربع أو بالمقطوعية.
- ضريبة اختيارية تُضاف إلى الإجمالي حسب طلب الشركة.
- أرشيف محلي وبحث وحذف.
- تصدير PDF إلى مجلد Downloads.
- اختبارات وحدات للتسعير والترقيم.
- GitHub Actions لبناء APK قابل للتثبيت.

## البناء
JDK 17 وAndroid SDK 35 وGradle 8.11.1:
```bash
gradle :app:testDebugUnitTest
gradle :app:assembleDebug
```

## تنزيل APK
كل تشغيل ناجح يرفع Artifact باسم `GOLDEN-SHINE-MARBLE-APK`.
يمكن تشغيل Workflow يدوياً من GitHub Actions لإنشاء GitHub Pre-release يحتوي ملف APK.

## ملاحظات المرحلة الحالية
النسخة الحالية أولية عملية: إدخال بند واحد لكل مستند، وتصدير PDF أساسي. تحرير المستندات، تعدد البنود داخل المستند، تنسيق PDF العربي التجاري الكامل، النسخ الاحتياطي، والتوقيع النهائي بمفتاح الشركة ما زالت ضمن الأعمال المتبقية.
