# GOLDEN SHINE MARBLE

تطبيق Android Native لإدارة عروض الأسعار وعقود المقاولات لشركة GOLDEN SHINE MARBLE.

## الوظائف الحالية
- Kotlin + Jetpack Compose بواجهة عربية RTL وتصميم داكن ولمسات ذهبية.
- قاعدة بيانات محلية Room لحفظ المستندات على الجهاز.
- نوعان من المستندات: عروض أسعار وعقود مقاولات، ولكل نوع تسلسل ترقيم مستقل.
- إضافة عدة بنود داخل المستند الواحد، مع إمكانية المزج بين التسعير بالمتر المربع والتسعير بالمقطوعية.
- حساب إجمالي البنود وضريبة القيمة المضافة الاختيارية.
- تعديل المستند مع الاحتفاظ برقمه وتاريخ إنشائه، وحذف المستند.
- أرشيف وبحث باسم العميل أو رقم المستند.
- إنشاء PDF بتنسيق A4 باللغة العربية أو الإنجليزية وحفظه في مجلد Downloads.
- تصدير نسخة احتياطية بصيغة JSON واستعادتها؛ الاستعادة تستبدل الأرشيف الحالي بعد تأكيد المستخدم.
- اختبارات وحدات لحسابات التسعير والضريبة والترقيم.
- GitHub Actions لاختبار المشروع وتجهيز APK ونشره كإصدار تجريبي.

## البناء
المتطلبات: JDK 17 وAndroid SDK 35 وGradle 8.11.1.
```bash
gradle :app:testDebugUnitTest
gradle :app:assembleDebug
```

## تنزيل APK
بعد نجاح GitHub Actions يتم نشر ملف APK ضمن صفحة Releases وإرفاقه أيضاً كـ Artifact باسم `GOLDEN-SHINE-MARBLE-APK`.

## ملاحظات الإصدار
ملف APK الناتج حالياً هو إصدار Debug موقع بمفتاح Android debug الافتراضي، وليس إصداراً إنتاجياً موقعاً بمفتاح الشركة. لإنتاج APK ثابت التوقيع قابل للتحديث فوق الإصدارات السابقة، أضف أسرار المستودع التالية من Settings ثم Secrets and variables ثم Actions: `ANDROID_KEYSTORE_BASE64` و`ANDROID_KEYSTORE_PASSWORD` و`ANDROID_KEY_ALIAS` و`ANDROID_KEY_PASSWORD`. عند غيابها ينشر CI نسخة Debug للتجربة فقط. كما يجب اختبار التثبيت وسلوك التطبيق على جهاز Android فعلي قبل اعتماده نهائياً.
